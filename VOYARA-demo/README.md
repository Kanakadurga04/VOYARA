# VOYARA – Travel Booking Platform (Next.js + TypeScript)

## Run
```
npm.cmd install
npm.cmd run dev
```
Open http://localhost:3000

## Demo accounts
- Admin: admin@voyara.com / admin123   (Admin Login page)
- User:  user@voyara.com / user123     (or sign up with your own email)

A "Demo mode" bar at the bottom switches between User and Admin live.
Data is stored in the browser (localStorage) – demo only.
